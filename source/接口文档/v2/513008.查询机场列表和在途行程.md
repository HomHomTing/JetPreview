### 查询机场列表和在途行程
接口地址=https://jet.huoli.com/jetgateway/pathForword

---
### 输入参数
| 参数名     | 类型     | 是否必填 | 备注           |
| ------- | ------ | ----------- | ------------ |
| pid    | String    | Y    | 接口ID，固定值 513008 |
| accountType     | String    | Y    | 固定值：web_map |
| authorizedUser    | String    | Y    | 用户标识，是一个JSON格式字符串例如：{"hlUserId":"96168449584896"} |
 ---

### 请求示例
```
curl --request POST \
  --url https://jet.huoli.com/jetgateway/pathForword \
  --header 'content-type: application/x-www-form-urlencoded' \
  --data pid=513008 \
  --data accountType=web_map \
  --data 'authorizedUser={"hlUserId":"96168449584896"}'
``` 

```
注1：会返回全球所有机场，包含每个机场停场的公务机数量，大概10000个左右
注2：会返回全球正在飞行的公务机，大概200-2000之间
```
