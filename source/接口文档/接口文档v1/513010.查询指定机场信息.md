### 查询指定机场信息
接口地址=<PRIVATE_API_BASE_URL>

---
### 输入参数
| 参数名     | 类型     | 是否必填 | 备注           |
| ------- | ------ | ----------- | ------------ |
| pid    | String    | Y    | 接口ID，固定值 513010 |
| accountType     | String    | Y    | 固定值：web_map |
| authorizedUser    | String    | Y    | 用户标识，是一个JSON格式字符串例如：{"hlUserId":"<HL_USER_ID>"} |
| airportCode     | String    | Y    | 机场三字码 |
 ---

### 请求示例
```
curl --request POST \
  --url <PRIVATE_API_BASE_URL> \
  --header 'content-type: application/x-www-form-urlencoded' \
  --data pid=513010 \
  --data accountType=web_map \
  --data airportCode=PEK \
  --data 'authorizedUser={"hlUserId":"<HL_USER_ID>"}'
```
