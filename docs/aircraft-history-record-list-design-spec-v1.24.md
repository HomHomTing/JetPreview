# 飞机历史飞行记录列表设计规范 1.24

## 1. 文档定位

本文档重做飞机详情面板「行程」段的历史飞行记录列表，承接 `docs/aircraft-history-timeline-design-spec-v1.22.md`，并沿用 `docs/airport-selected-panel-information-requirements-v1.23.md` 确立的设计语言（大屏版式列表、底部分段菜单、对比度规范）。

建议归属版本：`1.24`。
形成日期：2026-08-17。

本版本只梳理设计规范并给出原型，暂不实施代码。

可交互原型：https://claude.ai/code/artifact/e85cf7d2-28fc-44df-87b9-66d849633ee2

## 2. 行程段布局

自上而下固定为五块：

| 顺序 | 区块 | 说明 |
| --- | --- | --- |
| 1 | 当前状态卡 | 在途或停场，两张不同的卡片 |
| 2 | 周期切换 | `7d` / `30d` / `1y` |
| 3 | 行程汇总 | 航段数、飞行总时长，**随周期更新** |
| 4 | 活动图 | 柱状图，**随周期更新**，无标题文字 |
| 5 | 历史记录 | 大屏版式列表，按出发时间倒序 |

分段菜单位于面板底部，四段为 概览 / 航迹 / 信息 / 行程。

## 4. 当前状态卡片

两张卡结构对齐（同为「标题栏 + 主体」），但主视觉不同，使状态在扫读时即可分辨。

### 4.1 在途卡

| 项 | 规范 |
| --- | --- |
| 标题栏 | 左「当前在途」，右 `Live` 动作按钮（薄荷描边），点击回到实时地图并跟随 |
| 主视觉 | 航线两端机场码 17px 等宽 + 中间虚线航向箭头 |
| 进度 | 3px 进度条 + 上行「已飞 / 剩余」、下行「实际起飞 / 预计到达」 |
| 三格 | 高度、地速、升降率，与概览段口径一致 |
| 时区 | 两端时间各按本场时区，跨天在到达端标 `+1d` |

### 4.2 停场卡

| 项 | 规范 |
| --- | --- |
| 标题栏 | 左「当前停场」，右 `机场` 动作按钮，点击打开该机场面板 |
| 主视觉 | **停场时长做 30px 大字**，是停场状态下最关键的运行信息 |
| 位置 | 大字右侧为机场四字码 16px + 机场中文名与城市 |
| 三格 | 入场时间、上一段航线、上一段飞行时长 |
| 时长缺失 | 无 `groundTime` 时大字位显示 `—`，并保留接口原文（如「今日入场」）于其下，不猜测 |

停场时长做大字的理由：公务机绝大多数时间处于停场状态，「停了 3 天」与「停了 210 天」是完全不同的运行含义——前者是行程间隔，后者可能是维修或闲置。这与 v1.23 机场面板把停场时长做成分层维度是同一判断。

## 5. 周期切换与活动图

### 5.1 联动范围

| 项 | 规范 |
| --- | --- |
| 顺序 | 周期条 → 行程汇总 → 活动图 → 历史列表 |
| 汇总 | 航段数、飞行总时长两格，随周期更新 |
| 活动图 | 柱体与横坐标随周期更新 |
| 历史列表 | 同样按周期过滤，与汇总口径一致 |
| 取消的航段 | 计入航段数，但**不计入飞行总时长**，也不产生活动柱高 |

### 5.2 横坐标规范

| 周期 | 柱体粒度 | 横坐标格式 | 标注规则 |
| --- | --- | --- | --- |
| `7d` | 过去 7 天，每天一根 | `mm-dd` | 7 根全部标注 |
| `30d` | 过去 30 天，每天一根 | `dd` | 每 5 天标注一次；**跨月处改标月份缩写**并加重 |
| `1y` | 过去 12 个月，每月一根 | 月缩写 | 12 根全部标注，如 `Feb` `Aug` |

30d 若把 30 个 `dd` 全部标出，在 350px 宽度内必然重叠。因此规范为每 5 天标注一次，并在月份切换处以月缩写替代日期且加重显示——这样既满足「横坐标为 dd」，也满足「隔月情况下标注月份信息」。

### 5.3 悬停提示

| 项 | 规范 |
| --- | --- |
| 触发 | 鼠标悬停或键盘聚焦柱体；柱体同时转为高亮薄荷 |
| 内容 | 第一行为日期（7d/30d 为 `mm-dd`，1y 为 `YYYY Mon`），第二行为 `N 段 · Xh YYm` |
| 零值 | 当日无飞行时仍可悬停，提示显示 `0 段 · 无飞行`，柱体保留 2px 底座 |
| 定位 | 提示浮于柱体正上方居中；靠近左右边缘时贴边收拢，不溢出面板 |
| 触屏 | 无悬停时改为点击柱体弹出，再次点击或点击别处关闭 |

## 6. 历史记录列表

与 v1.23 机场面板同构的大屏版式，但列定义按「单机历史」调整。

| 列 | 宽度 | 内容 | 规范 |
| --- | --- | --- | --- |
| 日期 | 50px | 出发日期 + 星期 | 等宽 14.5px/600，`mm-dd`；下方星期缩写 |
| 航线 | 1fr | 三行：航线 / 起降时刻 / 机场名 | 航线等宽 13px 加粗；跨天在到达时刻后标 `+1d` |
| 时长 | 74px | 飞行时长 + 状态块 | 右对齐；状态仅在非「已落地」时用实底色 |

| 项 | 规范 |
| --- | --- |
| 排序 | 按出发时间**倒序**（最近在前）。历史记录是日志，与机场当日大屏的升序取向相反 |
| 月份分组 | sticky 月份标题，右侧显示当月航段数与累计时长 |
| 不重复机号 | 单机历史中注册号恒定，列表不再逐行重复，位置让给航线与时刻 |
| 状态配色 | 已落地为中性底（占绝大多数）；在途薄荷实底；取消珊瑚实底 + 整行 66% 透明 |
| 分段挂载 | 首屏 30 行，「加载更多」每次 +30；跳转与锚定规则沿用 v1.22 |

## 7. 验收标准

P0：

| 条目 | 判定方式 |
| --- | --- |
| 在途与停场各有独立卡片 | 两状态下卡片主视觉不同：在途为航线+进度，停场为时长大字 |
| 汇总仅两格且随周期更新 | 切换 7d/30d/1y，航段数与总时长数值改变；界面无「最近飞行日期」「常飞机场」 |
| 汇总位于周期条下方 | DOM 顺序为 周期条 → 汇总 → 活动图 |
| 活动图无标题文字 | 图表区不出现「年度活动」「近 30 天」字样 |
| 横坐标随周期切换 | 7d 为 mm-dd 共 7 根；30d 为 dd 共 30 根且跨月标月份；1y 为月缩写共 12 根 |
| 悬停显示具体数据 | 悬停任一柱体弹出该日/该月航段数与时长；零值也有提示 |
| 汇总与活动图口径一致 | 活动图各柱航段数之和等于汇总的航段数 |

P1：

| 条目 | 判定方式 |
| --- | --- |
| 列表为大屏版式 | 固定列头、斑马纹、状态色条、sticky 月份标题齐备 |
| 对比度全量达标 | 浅色与深色主题下不达标数均为 0；面板内字号 ≥ 11px（图表轴标签 9px 为唯一例外） |

## 8. 沿用 v1.22 未变更的部分

以下内容不重述，见 v1.22 第 3、7 章：

- 适配层需拆分五个独立时间 TimeRef（`scheduledDeparture` / `actualDeparture` / `scheduledArrival` / `actualArrival` / `estimatedArrival`）。
- `getFlightHistory()` 支持 range / page / filter。
- 移除 `renderFlightHistoryRows()` 的 6 条硬截断。
- `groundAirportInfo` 移出列表，由当前状态卡承载（本版即停场卡）。
- 后端需补充 `uniqueKey` / `totalCount` / `totalMinutes` / `delayMinutes`。
