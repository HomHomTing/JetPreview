# 航迹功能优化说明 1.15

## 目标

1.15 版本聚焦 selected 飞机航迹体验优化，不改变现有接口范围，不新增对外部动态数据依赖。

## 实施范围

- 保留 FR24 式默认高度色阶，`ALT` 仍为默认航迹模式。
- 保留 `SPD` 速度色阶作为分析模式，切换后地图航迹与左侧航迹面板同步。
- 将 selected 航迹语义分为实际航迹、估算/覆盖缺口、目的地计划连接三类。
- 为 selected 航迹保留透明交互命中层，仅用于更精准的选中与点击，取消航迹段 hover 诊断浮层。
- 左侧“航迹”Tab 取消航迹质量评估，仅保留速度与高度图表及实时高度、实时地速读数。
- 速度与高度图表横坐标固定为实际起飞时刻到当前时刻，坐标轴与 hover 同时展示 UTC 时间和航段当地时间，hover 时展示该时间点附近的高度与地速。
- Route 聚焦继续隐藏无关飞机和普通机场，仅保留 selected 飞机、航迹、端点和计划连接。

## 速度与高度图表

- 横坐标起点：实际起飞时刻；如果接口暂未返回实际起飞，则退回到航迹首个有效时间点。
- 横坐标终点：当前时刻，优先使用接口服务端时间，避免不同设备本地时区或系统时间影响。
- 当地时间口径：优先使用目的地机场时区；目的地未知时回退到出发机场时区；仍无法识别时回退 UTC。
- 数据补全：接口适配层保留数组型航迹点中的高度、地速、时间与航向；图表合并历史航迹点、起飞边界点和当前实时飞机点；高度与地速任一字段缺失时，在可控范围内以前后有效值补齐，hover 中用 `est.` 标记补齐值。
- 单位切换：速度与高度图表支持 `FT / KT` 和 `M / KMH` 两种单位；切换后坐标轴、hover 浮层、实时高度、实时地速读数同步换算。
- 横坐标：展示起点、中点、终点三组时间坐标；当地时间作为主信息，UTC 使用 `Z` 短格式作为辅助信息。
- 图表 hover：在鼠标位置附近吸附最近航迹点，优先显示完整当地时间，下一行显示完整 UTC 时间，并展示高度和地速。
- 实时读数：在图表下方展示当前飞机高度与当前地速。

## 验收点

- 点选飞机后 selected 航迹仍按高度色阶显示，不被 selected 状态改成单色。
- 覆盖缺口/估算段为深色虚线，不使用高度色阶。
- 当前点到目的地机场的计划连接为独立虚线，目的地未知时不显示。
- 速度与高度图表 hover 时出现十字线、吸附点、UTC/当地时间和高度/地速读数浮层。
- 速度与高度图表单位切换后，曲线形态保持一致，所有高度/地速文本读数同步切换到对应单位。
- 图表下方的起飞时刻与当前时刻读数必须同时包含 UTC 和换算后的当地时间。
- Route 聚焦时无关飞机和普通机场降噪，selected 航迹与端点保持可见。
