# 机场停场数量角标需求文档 1.20

## 1. 文档定位

本文档用于定义 1.20 版本中“机场停场公务机数量角标”的产品、数据、渲染和性能规则。

本需求只在现有机场 icon 右上角补充停场数量角标，不改变既有机场 icon 的加载、显隐、选中、hover、层级和密度控制逻辑。

建议归属版本：`1.20`。

形成日期：2026-08-19。

## 2. 目标

1. 地图加载机场坐标时，同步展示该机场当前停场公务机数量。
2. 用户在地图上能快速识别高停场量机场，辅助判断公务机运行密度。
3. 角标必须明显、清晰、可读，但不遮挡机场 icon 主体、机场浮窗、飞机 icon 和飞机注册号标签。
4. 数据加载必须复用现有轻量链路，不允许对每个机场逐个请求详情接口。
5. 渲染必须使用差量更新，避免拖拽、缩放、刷新时产生明显卡顿。

## 3. 数据来源

### 3.1 主数据源

主数据源使用 `513008 查询机场列表和在途行程` 返回的机场列表字段：

| 字段 | 含义 | 1.20 用途 |
| --- | --- | --- |
| `airportList[].airportCode` | 三字码 | 机场匹配键之一 |
| `airportList[].icaoCode` | 四字码 | 机场主匹配键 |
| `airportList[].lat` | 纬度 | 机场坐标 |
| `airportList[].lon` | 经度 | 机场坐标 |
| `airportList[].groundNum` | 当前停场公务机数量 | 地图角标数字 |
| `airportList[].level` / `displayLevel` | 机场展示层级 | 沿用现有机场显隐逻辑 |

`513008` 已返回全球机场列表和 `groundNum`，因此地图加载阶段不新增批量接口请求。

### 3.2 辅助数据源

辅助数据源只用于局部校准，不用于全量地图角标加载：

| 接口 | 使用场景 | 使用限制 |
| --- | --- | --- |
| `513010 查询指定机场信息` | 用户选中机场后，可用 `groundInfo.groundNum` 更新该机场角标 | 只更新当前选中机场 |
| `513014 查询指定机场的停场飞机` | 用户打开机场停场 tab 后，可用返回列表长度或 `groundInfo.groundNum` 校准角标 | 禁止地图全量循环调用 |

## 4. 显示规则

### 4.1 角标位置

角标固定在机场 icon 的右上角：

- 锚点相对于机场 pin 外框定位。
- 角标轻微压入机场 pin 右上角，形成“附着徽标”关系，避免机场密集区域中无法判断数字归属。
- 小机场 icon 的角标需要比大机场 icon 更贴近 pin，本身不额外扩大机场显示层级。
- 角标不参与地图点击命中，点击仍由机场 marker 处理。
- 角标层级高于机场 icon，低于机场 hover 浮窗、选中机场固定浮窗、飞机 icon 和飞机注册号标签。
- 角标必须作为机场 marker 内部元素渲染，随机场 marker 的创建、显隐和销毁同步变化。
- 当某个机场因地图层级、视口、密度上限或机场图层规则没有渲染 icon 时，该机场不得单独展示角标。

### 4.2 数字格式

| 停场数量 | 展示 | 样式 |
| ---: | --- | --- |
| `0` | `0` | 小圆形，低强调 |
| `1-9` | 原数字 | 圆形角标 |
| `10-99` | 原数字 | 短胶囊 |
| `100-999` | 原数字 | 中胶囊 |
| `>=1000` | `1k+`、`2k+` | 长胶囊，最多 4 个字符 |
| 缺失 / 非数字 | 不展示角标 | 不用 `-` 或 `N/A` 占位 |

说明：

- `0` 是有效业务值，需要展示，但颜色和阴影可比正数更克制。
- 缺失和非数字不等于 `0`，不得误显示为 `0`。
- 数字更新时只替换文本和尺寸档位，不销毁机场 marker。

### 4.3 尺寸规范

以当前机场 icon 约 `48px * 62px` 为参考，角标建议尺寸如下：

| 量级 | 最小宽度 | 高度 | 字号 | 用途 |
| --- | ---: | ---: | ---: | --- |
| `0-9` | `18px` | `18px` | `10.5px` | 单数字 |
| `10-99` | `26px` | `19px` | `11px` | 两位数 |
| `100-999` | `34px` | `20px` | `11px` | 三位数 |
| `1000+` | `42px` | `21px` | `11px` | 压缩数字 |

视觉原则：

- 使用黄色主色，与当前飞机 icon 色系保持一致，强化运行数据属性。
- 使用深色数字，保证地图底色上可读。
- 使用白色外描边和轻微投影，避免在深色道路、水面、山地区域丢失。
- 投影不应扩大为大面积阴影，避免与机场 pin 阴影叠加后变脏。
- 角标必须贴附在机场 pin 右上角，不得漂浮到机场坐标上方形成脱节感。
- 角标不得增加额外色块或连接片，避免遮挡黄色数字区域。
- 角标数字必须作为最高视觉层，不得被机场 pin 或描边遮挡。

## 5. 加载策略

### 5.1 首次加载

首次进入地图时：

1. 调用现有 `513008`。
2. 适配 `airportList` 时读取 `groundNum`，写入机场标准模型 `airport.ground`。
3. 地图按既有机场分层规则筛选可见机场。
4. 只为进入当前渲染队列的机场 marker 绘制角标，角标不得创建独立图层或脱离机场 marker 单独显示。

首屏不得新增以下行为：

- 不得遍历所有机场调用 `513010`。
- 不得遍历所有机场调用 `513014`。
- 不得在地图拖拽过程中连续请求停场详情。
- 不得因为角标数据尚未返回而阻塞飞机 icon 首次渲染。

### 5.2 后续刷新

角标数据跟随 `513008` 的机场列表刷新：

- 刷新频率沿用现有全局运行数据刷新节奏。
- 如果后续需要单独配置，建议最小刷新间隔不低于 `60s`。
- 数据刷新完成后，按机场键值做差量更新。
- 当前选中机场可使用 `513010` 或 `513014` 的结果局部覆盖，提升当前查看对象的准确性。

### 5.3 视口变更

地图拖拽和缩放时：

- 不重新请求停场数量，只复用已缓存的 `airport.ground`。
- 按既有机场显隐逻辑决定哪些机场 marker 可见。
- 新进入视口的机场 marker 创建时直接带上角标。
- 离开视口的机场 marker 随 marker 生命周期移除，不保留单独 DOM。
- 被机场分层规则过滤掉的机场，不渲染 icon，也不渲染停场数量角标。

## 6. 缓存策略

### 6.1 机场停场数量缓存

新增或明确使用一个轻量缓存：

```text
airportGroundCountCache: Map<airportKey, {
  value: number,
  source: "513008" | "513010" | "513014",
  updatedAt: number
}>
```

机场键值优先级：

```text
icaoCode > airportCode > id
```

### 6.2 缓存有效期

| 来源 | 建议 TTL | 说明 |
| --- | ---: | --- |
| `513008` | `60s-120s` | 地图全局数量 |
| `513010` | `60s` | 当前选中机场摘要 |
| `513014` | `30s-60s` | 当前选中机场停场详情 |

缓存过期不立即清空角标。旧值继续展示，直到新值返回后差量替换，避免数量闪烁。

## 7. 渲染性能要求

### 7.1 差量更新

机场角标更新必须满足：

- airport marker 已存在时，只更新角标 `textContent`、`data-count-tier` 和可见状态。
- 不因数量变化重建 Google / Leaflet marker。
- 不因数量变化触发全量 `renderAirports()`。
- 多个角标更新合并到一次 `requestAnimationFrame`。

### 7.2 DOM 数量控制

角标 DOM 数量不得超过当前可见且具备停场数量的机场 marker 数量，不为未渲染机场创建隐藏角标。

高密度地图下仍沿用现有机场分层加载规则；本需求不新增“展示全部机场角标”的例外。

### 7.3 文本测量控制

角标尺寸使用数量级 class / data 属性控制：

```text
data-count-tier="zero|single|double|triple|compact"
```

不得在每次刷新时逐个测量文本宽度，避免造成布局抖动。

## 8. 交互规则

### 8.1 Hover

地图上的机场常驻文字标签取消展示，任何缩放层级下均不展示机场名称、三字码或四字码标签。

机场 hover 浮窗继续展示既有机场标准信息：

```text
北京首都国际机场
Beijing Capital International Airport
PEK / ZBAA
```

1.20 不在 hover 浮窗中强制新增停场数量，避免浮窗信息变重。

### 8.2 选中机场

机场被选中后：

- 角标仍保留在机场 icon 右上角。
- 选中机场固定浮窗继续展示标准机场信息。
- 左侧机场停场 tab 中展示完整停场机队列表和构成。
- 如果详情接口返回的 `groundNum` 与地图角标不同，更新当前机场角标，并在调试台记录来源。

### 8.3 图层开关

机场图层状态沿用既有语义：

| 状态 | 角标行为 |
| --- | --- |
| `auto` | 对当前可见机场展示角标 |
| `on` | 对当前可见机场展示角标 |
| `off` | 普通机场和角标一起隐藏；selected / search / route endpoint 机场如保留，则角标也保留 |

## 9. 边界情况

1. `groundNum` 为字符串数字时，应转为 number。
2. `groundNum` 为负数、空字符串、`null`、`undefined` 时视为缺失，不展示角标。
3. 机场缺少三字码但有四字码时，仍可按四字码绑定角标。
4. 同一机场在接口中重复返回时，以四字码一致项合并，优先保留最新 `groundNum`。
5. 地图处于飞机关联航线查看状态时，不得因为角标更新导致飞机和航线层级变化。
6. iPad 和移动端上角标需要保留可读尺寸，但不扩大机场 marker 点击区域。

## 10. 调试台要求

仅本人可见的接口调试台可增加以下字段，方便核对：

| 字段 | 含义 |
| --- | --- |
| `airport.ground` | 当前页面使用的角标数量 |
| `raw.groundNum` | `513008` 原始停场数量 |
| `groundCountSource` | 当前数量来源 |
| `groundCountUpdatedAt` | 最近更新时间 |
| `badgeTier` | 当前角标尺寸档位 |

线上公开版本默认不展示调试台。

## 11. 验收标准

### 11.1 功能验收

- 地图首次加载后，可见机场右上角展示停场数量角标。
- `groundNum = 0` 时显示 `0`，缺失时不显示。
- 选中机场后，如详情接口返回更新数量，地图角标同步更新。
- 机场图层关闭时，普通机场角标随机场一起隐藏。
- 因地图层级或密度控制未展示机场 icon 时，该机场角标也必须隐藏。

### 11.2 性能验收

- 首屏不得新增按机场数量线性增长的详情接口请求。
- 地图拖拽、缩放时不得触发 `513010 / 513014` 批量请求。
- 角标更新不得导致机场 marker 全量销毁重建。
- 10000 个机场基础数据进入内存时，只渲染当前可见机场角标。
- 在中国、欧洲、美国东北部等机场密集区域缩放拖拽，不出现明显卡顿和数量闪烁。

### 11.3 视觉验收

- 角标明显可读，数量级越大胶囊越宽。
- 角标和机场 pin 视觉上保持贴合，能清楚判断归属机场。
- 角标不遮挡机场塔台主体或角标数字本身。
- 机场 hover 浮窗、选中机场浮窗、飞机 icon、飞机注册号标签不被角标盖住。
- 深色和浅色地图区域上均有足够对比度。

## 12. 非目标

以下内容不属于 1.20：

- 不新增机场停场详情的地图批量预加载。
- 不重做机场 icon 加载和密度控制规则。
- 不改变飞机 icon、飞机注册号标签、航迹绘制逻辑。
- 不新增机场聚合气泡。
- 不新增停场数量热力图。
