# Route Drawing Requirements 1.2

## 1. 文档定位

本需求文档用于 `Global BizJet Ops 1.2` 的航线、历史轨迹、估算航路与速度/高度可视化设计。目标是在交互视觉上贴近 Flightradar24 的航迹绘制习惯，同时保留本系统后续接入自有数据库后的可扩展性。

观察日期：2026-08-03。
参考来源：

- Flightradar24 官方支持文档：`https://support.fr24.com/support/solutions/articles/3000115027-why-does-the-aircraft-s-trail-change-colour-`
- Flightradar24 公共地图界面观察。
- 当前项目 1.2 代码中的 `setTrack`、`track-line` 与详情面板实现。

重要结论：

- FR24 官方说明中，选中飞机后的 trail 颜色默认表达高度，不是默认按速度上色。
- FR24 中黑色虚线用于表达无法接收信号时的估算航路，不应与真实历史轨迹混用。
- 本系统 1.2 应默认实现 FR24 风格的高度分段航迹；速度分段颜色作为独立分析模式提供。

## 2. 当前实现差距

当前实现：

- Leaflet 和 Google Maps 都使用单条 polyline 表达航迹。
- 普通航迹为黄色虚线。
- 选中航迹整条变为红橙色实线。
- 航迹没有根据每个点的高度或速度分段上色。
- 缺少估算航路、数据缺口、采样点 tooltip、色阶图例。

需要调整：

- 选中航迹不再整条变红，必须保留高度色阶。
- 选中状态通过线宽、外发光、层级、飞机 icon selected 状态表达。
- 航迹需要按 track point 分段绘制，每段可独立设置颜色、透明度和线宽。

## 3. 航线类型

| 类型 | 名称 | 颜色规则 | 是否交互 | 说明 |
| --- | --- | --- | --- | --- |
| `actualTrail` | 真实历史轨迹 | 默认按高度分段 | selected 时可 hover | 由 ADS-B/自有数据实际点生成 |
| `selectedTrail` | 选中航迹 | 保留高度分段，加粗/发光 | 是 | 不整条改红 |
| `estimatedRoute` | 估算航路 | 黑色或深灰虚线 | 否 | 无信号区间或推算路径 |
| `plannedRoute` | 计划航路 | 浅灰/浅黄长虚线 | 否 | 未来版本可展示飞行计划 |
| `groundTrail` | 地面/滑行轨迹 | 白色或浅灰 | 高 zoom 可交互 | 高度低于 100m/300ft 的路径 |
| `speedTrail` | 速度分析轨迹 | 按速度分段 | 是 | 非 FR24 默认，作为 1.2 分析模式 |

## 4. 数据模型

每个航迹点至少需要：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `lat` | number | 纬度 |
| `lng` | number | 经度 |
| `timestamp` | ISO string / number | 数据时间 |
| `altitudeFt` | number/null | 高度，英尺 |
| `altitudeM` | number/null | 高度，米，可由英尺换算 |
| `groundSpeedKt` | number/null | 地速，节 |
| `verticalSpeedFpm` | number/null | 垂直速度，英尺/分钟 |
| `heading` | number/null | 航向 |
| `source` | string | ADS-B、MLAT、自有数据库、估算等 |
| `isEstimated` | boolean | 是否估算点 |
| `quality` | string | `good`、`weak`、`estimated`、`invalid` |

数据处理规则：

- 相邻点时间差大于 180 秒，默认切断真实轨迹，改用 `estimatedRoute` 连接。
- 相邻点距离或速度异常时，不直接连线，标记为 `weak` 或断开。
- 高度缺失时使用上一有效高度；连续缺失超过 3 个点时使用中性灰。
- 速度缺失时速度模式使用中性灰，不影响高度模式。
- 所有绘制点保留原始时间戳，支持后续与速度/高度图表联动。

## 5. 高度色阶

默认模式为 `altitude`。航迹颜色根据每个轨迹点的高度插值计算。线段颜色取该段起点和终点高度的平均值。

FR24 官方表格给出的关键高度分段包括：`<100m`、`100m`、`4000m`、`6000m`、`11000m`、`12500m`、`13000m`，对应约 `<300ft`、`300ft`、`13100ft`、`19700ft`、`36100ft`、`41000ft`、`42600ft`。

建议实现色阶：

| 高度范围 | 英尺范围 | 视觉颜色 | 建议近似色值 |
| --- | --- | --- | --- |
| 地面/极低空 | `<300ft` | 白色 | `#ffffff` |
| 低空 | `300-13,100ft` | 黄到黄绿 | `#fff200 -> #b9e63a` |
| 中低空 | `13,100-19,700ft` | 绿到青色 | `#67d965 -> #25c9c7` |
| 中空 | `19,700-36,100ft` | 青蓝到深蓝 | `#21b7ef -> #2d46d0` |
| 高空 | `36,100-41,000ft` | 深蓝到紫色 | `#3f31bf -> #8b2ab0` |
| 超高空 | `41,000-42,600ft` | 紫红到红 | `#b62b82 -> #e53644` |
| 极高空 | `>42,600ft` | 红色 | `#ff3a2f` |

实现要求：

- 色阶需要连续插值，不使用突然跳变。
- 每段 polyline 必须独立着色。
- selected 状态仍然保留高度色阶。
- 高度图例应显示在地图右下或详情面板内，只有显示航迹时出现。
- 具体十六进制色值允许根据 FR24 截图人工采样微调，误差以视觉接近为准。

## 6. 速度色阶

速度色阶不是 FR24 默认航迹颜色语义，但本系统 1.2 可加入 `speed` 分析模式，供运营人员查看速度变化。

速度模式规则：

- 需要在 UI 中明确显示当前为 `Speed` 模式。
- 切换到速度模式后，航迹颜色由 `groundSpeedKt` 决定。
- 高度图例替换为速度图例。
- 默认进入页面仍使用高度模式。

建议速度色阶：

| 速度范围 | 运行状态 | 建议颜色 |
| --- | --- | --- |
| `<40kt` | 地面/滑行/悬停 | `#ffffff` |
| `40-120kt` | 低速飞行/小型机/直升机 | `#ffe45c` |
| `120-250kt` | 起降/爬升/进近 | `#60d66a` |
| `250-360kt` | 爬升或下降中段 | `#20c8c8` |
| `360-460kt` | 常规巡航 | `#2d8cf0` |
| `460-520kt` | 高速巡航 | `#7a35c7` |
| `>520kt` | 极高速/异常检查 | `#ff4b32` |

速度模式验收重点：

- 速度缺失时该段显示中性灰 `#9aa0a6`。
- 高速红色不能和 selected 状态冲突，selected 仍通过线宽/发光表达。
- 不同机型速度差异较大，后续可扩展为按 aircraft category 归一化速度色阶。

## 7. 线型与层级

### 7.1 真实航迹

- 线帽：round。
- 连接：round。
- 普通线宽：`2px-2.4px`。
- selected 线宽：`3px-3.4px`。
- 普通透明度：`0.62-0.72`。
- selected 透明度：`0.9-1.0`。
- selected 可增加一条深色外描边，宽度 `5px-6px`，透明度 `0.35-0.45`。

### 7.2 估算航路

- 黑色或深灰虚线。
- 线宽：`2px`。
- dash：`2px 8px` 或 Google Maps `repeat: 12px`。
- 透明度：`0.55-0.7`。
- 层级低于真实航迹。
- 不参与高度或速度色阶。

### 7.3 计划航路

- 非 1.2 必做。
- 使用浅灰或浅黄长虚线。
- 不与实际轨迹混色。
- 仅在有飞行计划数据时显示。

## 8. 缩放规则

| Zoom | 显示规则 |
| --- | --- |
| `2.0-3.9` | 隐藏普通未选中航迹；仅显示 selected 航迹，线宽减小 |
| `4.0-5.9` | 显示 selected 航迹和短历史轨迹；隐藏地面细节 |
| `6.0-8.9` | 显示完整 selected 航迹，普通航迹按设置显示 |
| `9.0-12.0` | 显示地面/滑行轨迹、采样点 hover、机场附近细节 |

性能约束：

- 低 zoom 必须简化点数，避免全量点导致地图卡顿。
- 每条 selected 航迹最多渲染 800 个可见分段；超过时做 Douglas-Peucker 或时间窗口抽样。
- 普通未选中航迹默认只显示最近 10 到 30 分钟。

## 9. 交互规范

点击飞机：

- 打开左侧详情面板。
- 显示该飞机完整 selected 航迹。
- selected 航迹保留高度/速度色阶，不整条改红。
- 航迹层级提升到普通航迹之上。

hover 航迹段：

- 显示 tooltip：时间、高度、速度、航向、坐标。
- 地图上可显示小型采样点，但默认只在 selected 航迹上启用。
- tooltip 不遮挡飞机 icon。

切换颜色模式：

- 入口放在 `Settings` 或未来 `Route` 工具面板。
- 支持 `Altitude`、`Speed`、`Source quality` 三种模式预留。
- 默认 `Altitude`。

图表联动：

- 左侧详情面板增加高度/速度小图表。
- hover 图表某个时间点时，地图航迹上显示对应点。
- hover 地图航迹段时，图表同步高亮同一时间段。

## 10. UI 图例

高度图例：

- 标题：`Altitude`
- 单位：默认 feet，悬停可显示 meters。
- 使用连续渐变条，不使用离散色块。
- 标注关键点：`300ft`、`13k`、`20k`、`36k`、`41k`、`43k+`。

速度图例：

- 标题：`Ground speed`
- 单位：kt。
- 标注关键点：`40`、`120`、`250`、`360`、`460`、`520+`。

显示规则：

- 无 selected 航迹且 trail 图层关闭时隐藏图例。
- 手机端图例默认收起，只保留当前模式标签。

## 11. 数据质量和异常显示

| 情况 | 显示要求 |
| --- | --- |
| 高度缺失 | 中性灰或沿用上一有效高度 |
| 速度缺失 | 速度模式中性灰 |
| 信号中断 | 真实轨迹断开，中间使用估算虚线 |
| 坐标跳变 | 断开，不连线 |
| 地面点 | 白色/浅灰，只有高 zoom 展示细节 |
| 未来预测 | 与真实轨迹分层显示，不使用高度色阶 |

## 12. 实现建议

Google Maps：

- 不再用单条 `google.maps.Polyline` 表示完整航迹。
- 每两个相邻 track points 生成一个 segment polyline。
- selected 外发光可用底层粗 polyline + 上层彩色 polyline 叠加。
- 估算航路使用 `icons` dash pattern 或分段虚线。

Leaflet fallback：

- 每个 segment 使用独立 `L.polyline`。
- selected 外发光使用双层 polyline。
- 地图移动/缩放时按可见区域裁剪或简化。

内部 API 建议：

```js
setTrackSegments(id, {
  points,
  selected,
  colorMode: "altitude",
  showEstimated: true,
  showSampleHover: true
});
```

## 13. 验收标准

1. selected 航迹根据高度分段显示颜色，不整条变红。
2. `<300ft` 轨迹接近白色，巡航高空轨迹逐步过渡到紫/红色。
3. 信号中断区间显示黑色或深灰虚线。
4. 切换速度模式后，航迹按速度分段变色，并显示速度图例。
5. hover selected 航迹段可查看时间、高度、速度、坐标。
6. 低 zoom 下未选中航迹不会造成地图拥挤。
7. 高 zoom 下机场附近地面轨迹可读。
8. Google Maps 和 Leaflet fallback 的航迹视觉规则一致。
9. 1000 个航迹点以内 selected 航迹渲染不卡顿。
10. 颜色图例和实际航迹颜色一致。

## 14. 1.2 优先级

P0：

- 高度分段真实航迹。
- selected 保留高度色阶。
- 黑色虚线估算航路。
- 高度图例。
- Google Maps 与 Leaflet fallback 支持。

P1：

- 速度分析模式。
- 航迹 hover tooltip。
- 数据缺口与异常点处理。
- 低 zoom 抽样简化。

P2：

- 高度/速度图表联动。
- 计划航路。
- Source quality 色阶。
- 多机同时高亮对比。
