# 1.1 Icon Interaction Specification

## 1. 文档定位

本规范用于 `Global BizJet Ops 1.1` 的地图 icon、工具 icon、面板 icon 与选中反馈设计。产品目标是让全球公务机运行数据系统在交互节奏、视觉层级、飞机图标形态和比例尺表现上尽量与 Flightradar24 类实时航班地图保持一致。实现上分为两种模式：已取得正式素材授权时接入授权图标资产；未取得授权时按同等视觉规范重绘自有图标，不直接复制第三方 SVG 路径、位图、商标或专有资源。

观察时间：2026-07-29。  
观察范围：Flightradar24 公共主页可见地图、顶部搜索/账户/菜单入口、地图标记视觉；用户提供的参考截图；当前项目 1.1 代码中的 Google Maps + Advanced Marker 实现。  
限制说明：自动化访问看到的是公共可见界面，未读取会员账户隐私、会话数据或专有资源包。Gold 会员账户可用于观察界面参考，但不等同于图标资产再发布授权。本文输出的是可落地交互视觉规范和授权接入要求，不是第三方资产清单。

## 2. 设计原则

1. 地图是主界面，所有 icon 必须服务于地图读取，不抢占地图层级。
2. 飞机 icon 是最高优先级地图符号，必须在浅色陆地、蓝绿色海面、灰度遮罩上都清晰。
3. 机场 icon 是第二优先级地图符号，密度低于飞机，默认弱于飞机，选中后可提升到同等层级。
4. 工具 icon 使用线性白色图标，不使用复杂插画；功能状态通过背景、描边、黄色高亮和面板开合表达。
5. 所有选中状态必须有唯一颜色，不能只靠阴影或尺寸区分。
6. icon 必须跟随地图经纬度锁定，不允许在 Google Maps 模式使用独立绝对定位层模拟坐标。
7. 遮罩层只能作用于底图，不能覆盖飞机、机场、标签、路线和面板。

## 3. 地图图层顺序

从底到顶：

1. Google Maps 底图。
2. 地图灰度/暗色对比遮罩，透明度控制在 10% 到 15%。
3. 天气、云图、雷达等非交互覆盖层。
4. 航迹线、选中航线、航班路径。
5. 机场 marker。
6. 飞机 marker。
7. marker 文本标签。
8. 左侧详情面板、搜索结果、过滤面板、底部工具栏、右侧菜单。

实现约束：

- Google Maps 模式必须使用 `AdvancedMarkerElement` 或同等级地图原生 marker 能力。
- 飞机/机场 icon 坐标必须由地图引擎管理，支持拖拽、缩放、旋转、窗口变化时自动跟随。
- 选中的 marker 使用更高 `z-index`，保证不会被普通 marker 或标签遮挡。

## 5. 飞机 Marker 规范

### 5.0 Flightradar24 飞机图标复刻边界

产品要求：

- 飞机 icon 的视觉语言、颜色、朝向、尺寸变化、选中反馈需要与 Flightradar24 保持同屏一致。
- 不同机型需要对应不同飞机轮廓，不能所有公务机共用同一个飞机图形。
- 地图在不同 zoom 比例尺下，飞机 icon 的屏幕尺寸、标签显隐、点击热区需要按 Flightradar24 的表现校准。

资产接入模式：

| 模式 | 使用条件 | 实现要求 |
| --- | --- | --- |
| `licensed-fr24-assets` | 已取得 Flightradar24 或权利方对图标资产的明确书面授权 | 可接入授权 SVG/PNG/WebP 资产；必须记录授权来源、使用范围、文件 checksum 和版本 |
| `custom-equivalent-assets` | 未取得正式素材授权 | 由本项目重绘俯视飞机轮廓，匹配 Flightradar24 的视觉比例、颜色、尺寸与状态，不复制第三方源文件 |

工程默认采用 `custom-equivalent-assets`。如果后续提供正式授权素材包，再切换为 `licensed-fr24-assets`。

### 5.1 默认形态

- 类型：俯视飞机剪影；若有授权资产，使用授权图标；否则使用自有重绘等效图标。
- 朝向：按照航向角实时旋转，机头指向飞行方向。
- 主色：黄色。
- 描边：深色细描边，保证在浅色陆地上可读。
- 阴影：局部椭圆阴影 + drop-shadow，位于飞机图形下方。
- 点击热区：桌面不少于 `44 x 44px`，触屏不少于 `48 x 48px`，视觉主体可小于热区。
- 标签：默认显示 callsign，位于飞机右侧偏中位置，深色矩形小标签。

中 zoom 基准尺寸：

| 飞机类型 | 视觉主体尺寸 | 热区尺寸 | 使用场景 |
| --- | --- | --- | --- |
| Light jet | 22px | 44px | PC-24、Citation 小型机 |
| Midsize | 24px | 44px | Citation Longitude、Challenger 300/350 |
| Super midsize | 26px | 44px | Praetor 600、Challenger 350/650 |
| Long range | 28px | 44px | Falcon 7X/8X、Gulfstream G500/G550 |
| Ultra long | 30px | 44px | Gulfstream G650、Global 6000/7500 |

### 5.2 机型区分

不同公务机类型只允许通过轮廓、尺寸、机翼比例、机身长度、翼尖/尾翼形态和标签信息区分，不引入额外颜色体系。颜色越多会削弱实时地图的扫描效率。

推荐分类：

| 分类 | 轮廓特征 | 典型机型 | 视觉重点 |
| --- | --- | --- | --- |
| `light` | 短机身、窄翼展、小尾翼、机鼻短 | PC-24、Citation CJ/Latitude | 小而清晰，机翼不夸张 |
| `midsize` | 中等机身、轻微后掠翼、尾翼更明显 | Citation Longitude、Learjet、Challenger 300 | 与 light 拉开 2px 左右 |
| `super-midsize` | 机身更长、翼展更宽、后掠感更强 | Praetor 600、Challenger 350/650 | 轮廓介于 midsize 与 long-range |
| `long-range` | 长机身、宽翼展、尾翼和翼尖更醒目 | Falcon 7X/8X、Gulfstream G500/G550 | 远程公务机主力样式 |
| `ultra-long` | 最长机身、最大翼展、翼尖细节明显 | Global 6000/7500、Gulfstream G650/G700 | 地图上最大公务机轮廓 |

映射规则：

- 数据层必须维护 `aircraftTypeCode`、`manufacturer`、`model`、`sizeClass`。
- 渲染层只读取 `sizeClass` 与 `heading`，不要在组件里硬编码机型判断。
- 未识别机型默认落入 `midsize`，并在数据质量日志中记录。
- 同一比例尺下，相邻分类尺寸差建议 `2px`，外形差异优先于颜色差异。

### 5.3 比例尺尺寸矩阵

飞机 icon 尺寸使用屏幕像素，不使用真实机身米数缩放。地图可以无级缩放，但 icon 尺寸按 zoom 区间插值或阶梯切换，目标是在同屏视觉上接近 Flightradar24。

| Google Maps zoom | 地图视图 | Light | Midsize | Super midsize | Long range | Ultra long | 标签规则 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| `2.0-2.9` | 全球 | 14px | 15px | 16px | 17px | 18px | 默认隐藏，仅 selected/hover 显示 |
| `3.0-3.9` | 洲际 | 16px | 17px | 18px | 19px | 20px | 高密度隐藏，selected 显示 |
| `4.0-4.9` | 大区 | 18px | 20px | 21px | 22px | 23px | selected/hover 显示，低密度可显示 |
| `5.0-5.9` | 国家/航路 | 20px | 22px | 24px | 26px | 27px | 可显示主要 callsign |
| `6.0-6.9` | 区域 | 22px | 24px | 26px | 28px | 30px | 默认显示，拥挤区域隐藏 |
| `7.0-8.9` | 城市群 | 24px | 27px | 29px | 31px | 33px | 默认显示，hover 提升层级 |
| `9.0-12.0` | 机场/城市 | 26px | 29px | 32px | 34px | 36px | 默认显示，selected 标签红底 |

选中状态尺寸：

- 视觉主体在当前 zoom 尺寸基础上增加 `2px`，上限 `40px`。
- 点击热区不随视觉主体缩小，始终不少于 `44px`。
- 移动端视觉主体可使用 `0.92` 倍缩放，但热区仍保持 `48px`。

校准方法：

- 在 `1920 x 1080` 与 `1440 x 900` 两个桌面视口截图对比。
- 分别在 zoom `2.5`、`4.5`、`6.5`、`8.5`、`10.5` 抽样测量 10 个普通飞机、3 个选中飞机。
- 与 Flightradar24 参考截图的 icon 外接矩形误差控制在 `±2px`。
- 选中颜色、标签位置和航迹宽度通过截图叠加校验，视觉差异超过 `8%` 需要返工。

### 5.4 Hover 状态

- 鼠标进入热区后，飞机提高亮度，阴影略增强。
- 标签保持可见；如当前处于标签关闭模式，只在 hover 时临时显示标签。
- 不改变地图中心，不打开面板。
- 过渡时长建议 `100-140ms`，避免拖动地图时出现拖影。

### 5.5 Selected 状态

- 飞机主体切换为红橙色。
- 描边切换为接近白色。
- 阴影加入红色外发光，层级提升到所有普通飞机上方。
- 航迹线同步切换为红橙色实线或更强不透明度。
- 左侧详情面板打开，展示航班信息。
- 再点击其他飞机，当前选中状态转移；关闭详情面板时清空选中。

### 5.6 密度与缩放

- 全球低 zoom：保留飞机主体，不强制显示全部 labels。
- 区域中 zoom：显示主要 callsign 标签，航迹线可见。
- 机场/城市高 zoom：显示更多标签、选中航迹、机场点。
- 大量飞机聚集时优先隐藏标签，而不是缩小飞机到不可辨识。
- V1.1 静态数据量较小，不做聚合；未来高密度数据应进入 Canvas/WebGL 渲染。

### 5.7 资产文件规范

若使用授权资产，文件组织建议：

```text
assets/
  aircraft-icons/
    licensed-fr24/
      light.svg
      midsize.svg
      super-midsize.svg
      long-range.svg
      ultra-long.svg
      manifest.json
    custom-equivalent/
      light.svg
      midsize.svg
      super-midsize.svg
      long-range.svg
      ultra-long.svg
      manifest.json
```

`manifest.json` 必须记录：

- `sourceMode`: `licensed-fr24-assets` 或 `custom-equivalent-assets`。
- `license`: 授权说明；自有图标则写 `owned-custom`.
- `sourceVersion`: 图标来源版本或设计版本。
- `sizeClass`: 对应 `light`、`midsize`、`super-midsize`、`long-range`、`ultra-long`。
- `viewBox`: 统一建议 `0 0 64 64`。
- `anchor`: 默认 `{ "x": 32, "y": 32 }`，以图标中心为地图坐标锚点。
- `strokePolicy`: 默认深色描边，selected 可切白色描边。

## 6. 机场 Marker 规范

### 6.1 默认形态

- 类型：圆点/环形机场点，不使用复杂航站楼插画。
- 主体：蓝色圆点。
- 描边：白色内环或外环。
- 阴影：小范围暗色投影。
- 标签：机场 ICAO 或 IATA 代码，默认在点位下方，深色底。
- 热区：不少于 `34 x 34px`。

建议值：

| 元素 | 建议值 |
| --- | --- |
| 热区 | 34px |
| 圆点主体 | 15px |
| 默认填充 | `rgba(43,128,205,0.92)` |
| 默认描边 | `rgba(255,255,255,0.92)` |
| 标签字号 | 11px |

### 6.2 Hover 状态

- 圆点外环增强。
- 标签保持清晰，不改变面板。
- 鼠标样式为 pointer。

### 6.3 Selected 状态

- 圆点主体切换为红橙色。
- 外围增加黄色柔和光环与红色第二层光环。
- 标签底色切换为红色。
- 左侧详情面板切换到机场信息视图。
- 相关公务机列表中的航班可继续点击跳转到飞机详情。

### 6.4 显示规则

- 全球 zoom 下仅显示主要公务机运行机场。
- 区域 zoom 下显示业务机场、备降机场、FBO 重点机场。
- 城市 zoom 下可显示跑道/地面状态入口，但 V1.1 暂不实现地面图标。

## 7. 航迹与路线 Icon 规范

航迹不是传统 icon，但在交互层级上必须和飞机 marker 联动。

- 默认航迹：黄色虚线，低不透明度。
- 选中航迹：红橙色，线宽增加，不使用虚线。
- 历史轨迹：低透明度，不阻挡机场/飞机。
- 计划航线：可用更浅黄色虚线，与真实轨迹区分。
- 路线箭头：左侧详情中使用细线箭头，不使用实体飞机图标。

## 9. 过滤面板 Icon 与控件规范

V1.1 过滤只允许 Business Jet 类型飞机：

- `Business Jet` 选项固定勾选并禁用。
- 禁用项背景使用低透明黄色提示“当前版本锁定”。
- 标签、航迹、机场显示可作为普通 checkbox/toggle。
- 面板底色为深灰，顶部标题区和关闭 icon 固定。
- 不允许加入额外彩色机型 icon，防止误导为支持多类型飞机。

后续版本如加入更多过滤：

- Aircraft type 使用飞机轮廓小 icon。
- Altitude 使用高度层/阶梯线 icon。
- Speed 使用速度表 icon。
- Airport status 使用机场点 + 状态圆点。
- Weather 使用云/雨/风图标。
- 每个过滤项必须有 default、selected、disabled 三态。

## 10. 左侧详情面板 Icon 规范

飞机详情面板：

- 顶部 tab：`Flight`、`Aircraft`，active 使用黄色底 + 黑字。
- 关闭 icon 位于右上，不占用 tab 语义。
- 航线模块用起飞机场代码、箭头线、到达机场代码表达。
- 飞机类型徽章使用圆形文字徽章，不放第三方飞机图片。
- 数据源可使用 badge/receiver icon，但 V1.1 只显示文本。

机场详情面板：

- Hero 区右侧使用线性机场 icon 或圆形机场符号。
- 信息结构包含城市、国家、坐标、海拔、天气、延误、起降、地面飞机、跑道。
- 相关航班列表右侧使用 chevron，点击进入飞机详情。
- 选中机场 marker 与面板标题必须同步。

## 12. 手势与交互规则

- 单击飞机：选中飞机，打开左侧飞机详情，地图可轻微平移至可见区域。
- 单击机场：选中机场，打开左侧机场详情，地图可轻微平移至可见区域。
- 点击空白地图：V1.1 可保留当前选中；后续可配置为清空选中。
- 拖拽地图：不改变选中状态；marker 必须跟随经纬度锁定。
- 缩放地图：支持平滑缩放；飞机 marker 屏幕尺寸按 `5.3 比例尺尺寸矩阵` 控制，避免全球视图过大、机场视图过小。
- 触屏：点击热区不低于 44px；底部工具栏按钮不低于 58px 高。
- Escape：关闭过滤/搜索结果；是否关闭详情面板由产品配置决定。

## 13. 可访问性与工程约束

- 每个可点击 icon 必须有 `aria-label` 或可读文本。
- 纯装饰 icon 标记为 `aria-hidden="true"`。
- 线性工具 icon 使用 `currentColor`，方便 hover/active 统一控制。
- marker 不能依赖图片加载成功才可点击。
- 所有 hover/active 不得改变按钮外部尺寸，避免地图 UI 抖动。
- 高对比遮罩不得超过 15% 基础透明度，且必须位于 marker 下方。
- 不在生产代码中引用第三方站点未授权 icon URL。
- Gold 会员账户只用于界面观察，不作为 icon 资产复制、下载、缓存提取或再发布依据。
- 若启用 `licensed-fr24-assets`，必须先完成授权文件归档，再进入开发接入。
