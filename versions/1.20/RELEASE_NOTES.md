# 1.20 版本发布说明

封存/发布日期：2026-08-19

## 版本基线

- 首页发布版本号统一为 `Business Jet Radar 1.20`，静态资源缓存串统一为 `1.20-release`。
- 继续使用自有数据库接口，机场详情和动态列表综合使用 `513008`、`513010`、`513013`、`513014`、`513015`。
- 飞机 icon、选中航迹与 ICAO Code 映射继续沿用既有稳定基线。
- 机场加载以 `docs/fr24-airport-loading-rules-simplified-v1.20.md` 为当前标准。

## 主要更新

- 机场详情改为停场、动态、运行、机场四个业务 Tab，并重新组织基础信息和运行状态字段。
- 停场机队展示全部返回飞机，使用明文注册号，支持即将入场、停场时长、搜索、排序、按机型及品牌归纳。
- 机场动态采用时间轴卡片，完整展示起止机场中文名、三字码、四字码、当地起飞/到达时刻、完整机型和状态。
- 对缺失起飞机场的机场动态记录，通过 `513013` 历史行程进行机场、航班和到达时间匹配补全。
- 地图机场 pin 新增停场数量角标，并与机场 icon 共用视觉容器和缩放显隐生命周期。
- 修复图标尺寸已经归零但角标仍显示的问题，选中、悬停和航线端点机场继续按保护规则显示。
- 取消所有比例尺下的机场常驻文字标签，完整名称和代码只在 hover 或选中状态出现。
- 保留并继续优化 1.19 的 365 天飞机历史行程时间轴和滚动稳定性。

## 验证要求

- `node --check app.js`
- `node --check data-service.js`
- `node --test tests/*.test.cjs`
- 在线工作区执行 `npm test`，确认公开预览 iframe 指向 `/map/v1-20.html`，并包含 1.20 地图资源。

## 发布范围

- 主仓库同步到 GitHub，并打 `v1.20` 标签。
- 当前 1.20 版本发布到在线预览工作区。
- `config.js` 仍不进入主仓库；在线预览工作区继续携带已授权的浏览器端运行配置。
