# Global BizJet Ops 1.1 PRD

## 1. 版本目标

V1.1 在 V1.0 静态演示版基础上，优化全球公务机运行地图的地图交互、飞机图标体系、机场点位、选中反馈与视觉对比。该版本继续使用虚拟静态数据，不接入实时航班数据和自有数据库。

界面交互目标：地图、飞机、机场、详情面板、搜索、过滤和工具栏的视觉规范尽量与 Flightradar24 类实时航班地图保持一致，同时取消第三方品牌露出。

## 2. 范围说明

本版本包含：

- Google Maps 作为默认地图基底。
- 地图拖拽、平滑缩放、上下边界限制。
- 地图灰度/暗色对比遮罩，透明度 10% 到 15%。
- 全球公务机静态样例数据。
- 机场静态样例数据。
- 飞机和机场坐标固定在经纬度位置，跟随地图缩放和平移。
- 飞机/机场点击后打开左侧详情面板。
- 过滤面板仅保留 Business Jet 类型。
- 飞机图标按新 icon 规范进行分类、尺寸与状态定义。

本版本不包含：

- 实时航班动态数据接入。
- 用户会员登录功能。
- Flightradar24 品牌露出。
- 未授权复制第三方 SVG、PNG、字体、缓存文件或商标素材。
- 非 Business Jet 飞机类型展示。

## 3. 用户角色

| 角色 | 目标 |
| --- | --- |
| 运营查看人员 | 在全球地图上快速查看公务机运行态势、航线、机场活动 |
| 航班调度人员 | 搜索公务机、查看航班详情、查看相关机场动态 |
| 产品/设计人员 | 对齐 Flightradar24 类实时地图的交互视觉规范 |
| 后端/数据人员 | 后续用自有数据库替换静态数据 |

## 4. 核心功能需求

### 4.1 地图基底

- 默认加载 Google Maps。
- 支持拖拽、滚轮缩放、触控缩放。
- 支持无级/平滑缩放体验。
- 地图拖拽到顶部或底部边界时停止继续拖拽。
- Google Maps API key 通过 `config.js` 配置。
- Google Maps 加载失败时允许进入本地 fallback 地图，但需要保留飞机、机场和详情面板功能。

### 4.2 地图视觉遮罩

- 在地图底图和飞机/机场 icon 之间增加灰度/暗色遮罩层。
- 遮罩基础透明度控制在 10% 到 15%。
- 遮罩必须提升黄色飞机与地图底图对比度。
- 遮罩不能压在飞机、机场、标签、航迹和 UI 面板之上。

### 4.3 飞机数据

- V1.1 使用虚拟静态公务机数据。
- 每架飞机至少包含：

| 字段 | 说明 |
| --- | --- |
| `id` | 系统内部唯一 ID |
| `callsign` | 航班号/呼号 |
| `registration` | 注册号 |
| `manufacturer` | 制造商 |
| `model` | 机型 |
| `aircraftTypeCode` | 机型代码 |
| `sizeClass` | 图标分类 |
| `operator` | 运营方 |
| `from` | 起飞机场 ICAO |
| `to` | 到达机场 ICAO |
| `lat/lng` 或 `route/progress` | 当前坐标或路径进度 |
| `heading` | 航向角 |
| `altitude` | 高度 |
| `speed` | 地速 |
| `verticalSpeed` | 垂直速度 |
| `squawk` | 应答机编码 |
| `status` | 运行状态 |
| `source` | 数据源 |

### 4.4 飞机图标需求

产品要求飞机 icon 的视觉语言、颜色、朝向、尺寸变化、机型差异和选中反馈与 Flightradar24 保持同屏一致。

授权与实现规则：

- 若取得 Flightradar24 或权利方明确书面授权，可直接接入授权飞机 icon 资产。
- 授权资产需要记录来源、授权范围、版本、checksum 和 manifest。
- Gold 会员账户只用于观察界面参考，不作为图标资产复制、下载、缓存提取或再发布依据。
- 未取得正式授权时，必须使用本项目自有重绘的视觉等效 icon，匹配比例、颜色、尺寸和状态，不复制第三方源文件。
- 默认工程模式为 `custom-equivalent-assets`；提供正式授权素材后可切换为 `licensed-fr24-assets`。

飞机 icon 映射：

- 数据层维护 `aircraftTypeCode`、`sizeClass`、`fr24IconKey`。
- 当前 Business Jet 样例统一映射到 `lj45` 公务机图标键。
- `sizeClass` 只控制地图 zoom 下的视觉主体尺寸，不再决定 SVG 轮廓。
- 完整当前映射见 `docs/aircraft-icon-mapping-v1.1.md`。

飞机 sizeClass 分类：

| 分类 | 轮廓特征 | 典型机型 | 渲染要求 |
| --- | --- | --- | --- |
| `light` | 短机身、窄翼展、小尾翼、机鼻短 | PC-24、Citation CJ/Latitude | 最小公务机轮廓 |
| `midsize` | 中等机身、轻微后掠翼、尾翼更明显 | Citation Longitude、Learjet、Challenger 300 | 与 light 拉开明显尺寸 |
| `super-midsize` | 机身更长、翼展更宽、后掠感更强 | Praetor 600、Challenger 350/650 | 介于 midsize 与 long-range |
| `long-range` | 长机身、宽翼展、尾翼和翼尖更醒目 | Falcon 7X/8X、Gulfstream G500/G550 | 远程公务机主力样式 |
| `ultra-long` | 最长机身、最大翼展、翼尖细节明显 | Global 6000/7500、Gulfstream G650/G700 | 最大公务机轮廓 |

地图比例尺下的飞机 icon 尺寸：

| Google Maps zoom | 地图视图 | Light | Midsize | Super midsize | Long range | Ultra long | 标签规则 |
| --- | --- | ---: | ---: | ---: | ---: | ---: | --- |
| `2.0-2.9` | 全球 | 20px | 22px | 24px | 26px | 28px | 默认隐藏，仅 selected/hover 显示 |
| `3.0-3.9` | 洲际 | 22px | 25px | 27px | 29px | 31px | 高密度隐藏，selected 显示 |
| `4.0-4.9` | 大区 | 25px | 28px | 31px | 33px | 35px | selected/hover 显示，低密度可显示 |
| `5.0-5.9` | 国家/航路 | 28px | 32px | 35px | 38px | 40px | 可显示主要 callsign |
| `6.0-6.9` | 区域 | 31px | 35px | 38px | 41px | 44px | 默认显示，拥挤区域隐藏 |
| `7.0-8.9` | 城市群 | 33px | 38px | 42px | 45px | 48px | 默认显示，hover 提升层级 |
| `9.0-12.0` | 机场/城市 | 35px | 40px | 45px | 48px | 52px | 默认显示，selected 标签红底 |

飞机 icon 状态：

| 状态 | 要求 |
| --- | --- |
| Default | 黄色主体、深色描边、局部阴影、按 heading 旋转 |
| Hover | 亮度和阴影增强，可临时显示 callsign 标签 |
| Selected | 红橙主体、白色描边、红色外发光、层级提升 |
| Hidden | 过滤或视口外时不渲染 |
| Loading/Error | 保持地图可操作，不阻塞其他 marker |

尺寸与交互约束：

- 飞机 icon 尺寸使用屏幕像素，不按真实机身米数缩放。
- 地图无级缩放时，icon 尺寸可按 zoom 区间插值或阶梯切换。
- 选中状态在当前 zoom 尺寸基础上增加 `3px`，上限 `56px`。
- 桌面点击热区不低于 `64 x 64px`。
- 触屏点击热区不低于 `64 x 64px`。
- 飞机标签位于机体右侧偏中位置，深色底白字。
- 高密度区域优先隐藏标签，不把飞机缩小到不可辨识。

### 4.5 机场数据与图标

- 地图上展示机场坐标点。
- 机场点默认蓝色圆点 + 白色描边。
- 机场选中后切换为红橙点 + 黄色/红色光环。
- 点击机场后打开左侧机场详情。
- 机场详情至少包含城市、国家、坐标、海拔、天气、延误、起飞、到达、地面飞机、跑道、相关公务机。

### 4.6 左侧详情面板

飞机详情：

- 点击飞机后打开。
- 显示航班状态、呼号、注册号、机型、运营方、起飞机场、到达机场、计划/预计时间、飞行进度、高度、速度、垂直速度、航向、坐标、squawk、数据源。
- 选中飞机与航迹同步高亮。

机场详情：

- 点击机场后打开。
- 显示机场基础信息、运行动态和相关公务机列表。
- 点击相关公务机可切换到飞机详情。

### 4.7 搜索

- 支持搜索呼号、注册号、机型、运营方、机场 ICAO/IATA、机场名称、城市和国家。
- 搜索结果区分 `Jet` 与 `Airport`。
- 点击结果后定位地图并打开对应详情。

### 4.8 过滤

- V1.1 锁定只显示 Business Jet。
- `Business Jet` 选项固定勾选并禁用。
- 标签、航迹、机场显示可独立开关。

### 4.9 工具栏

- 顶部：账户、搜索、菜单。
- 底部：设置、天气、过滤。
- 地图：定位/回到默认视图。
- 所有工具 icon 使用统一线性风格，hover/active 不改变布局尺寸。

## 5. 非功能需求

### 5.1 性能

- 首屏地图加载优先级高于面板内容。
- 静态数据阶段 marker 数量小于 500 时使用 DOM/Advanced Marker。
- 后续数据量超过数千架飞机时，飞机层应迁移到 Canvas 或 WebGL。
- 地图拖拽和缩放期间 marker 不能明显漂移、卡顿或闪烁。

### 5.2 兼容性

- 支持桌面 Chrome/Safari。
- 支持移动端基础触控操作。
- Google Maps 失败时可用 fallback 地图展示核心功能。

### 5.3 安全与合规

- 不在网页中添加 Flightradar24 会员登录功能。
- 不读取、保存或展示会员账户隐私。
- 不暴露 Google Maps API key 到文档或回复中。
- 不使用未授权第三方 icon 资产。

## 6. 验收标准

1. 默认加载 Google Maps，支持拖拽、平滑缩放和上下边界限制。
2. 飞机和机场坐标随地图联动，不发生漂移。
3. 飞机 icon 按 `aircraftTypeCode -> fr24IconKey` 映射展示，当前 Business Jet 样例映射到 `lj45`。
4. 飞机 icon 在 zoom `2.0-12.0` 范围内符合尺寸矩阵。
5. 飞机 icon 与 Flightradar24 参考截图外接矩形误差控制在 `±2px`。
6. 飞机默认黄色，选中红橙色，hover/selected 状态清晰。
7. 选中飞机后，飞机 icon、航迹、左侧详情同步更新。
8. 机场默认蓝点白环，选中后红橙点和光环同步出现。
9. 遮罩透明度保持 10% 到 15%，不影响地图文字和地理元素读取。
10. 过滤面板仅允许 Business Jet 类型。
11. 页面不出现 Flightradar24 品牌露出。
12. 未提供授权素材时，不引用或复制第三方 icon 文件。
